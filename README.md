# HI HOME — «Портфолио 2026»

Статический одностраничный лендинг на HTML, CSS и Vanilla JavaScript.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 8080
```

После этого страница будет доступна по адресу `http://localhost:8080`.

## Публикация

Папку проекта можно перетащить в Netlify Drop или импортировать в Vercel как статический проект без build-команды.

## Подключение формы

В `index.html` у формы `#lead-form` укажите `action` выбранного сервиса (например, Formspree) и уберите демонстрационный обработчик `submit` в `script.js`. До подключения endpoint данные намеренно не отправляются.
